# Figure outputs

Run `python scripts/plot_figures.py` to write PDF and PNG quantitative redraws
to `figures/reproduced/`. These outputs are generated and ignored by Git.

Figures 2–5 are redrawn from committed derived Source Data, except Figure 5
panel c. That panel is IMvigor210 comparison context: accession and
paper-reported summary AUC/CI/P only. Sample-level IMvigor scores are not
in this repository and are not a LEVEL 2 redraw.

Figure 1 is conceptual author artwork and is not code-generated here. Final
editorial Adobe composition of Figures 1, 4 and 5 is outside the public
repository. The scripts do not claim pixel identity with those publication
boards.
